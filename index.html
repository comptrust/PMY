Avis Déploiement GitHub Pages :
Si cette page reste affichée, votre dépôt GitHub Pages est configuré pour servir le code source non compilé.
  1. Allez dans votre dépôt GitHub : Settings > Pages
  2. Sous Build and deployment > Source, choisissez GitHub Actions (au lieu de Deploy from a branch).
  3. L'action automatique compilera le site et affichera l'interface complète sans écran blanc.
